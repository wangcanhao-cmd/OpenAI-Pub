AirTag 位置导入

仅本机处理

在 iPhone「查找」选择自己的 AirTag →「路线」→ 在 Apple 地图分享目的地链接。将链接粘贴在这里，提取其中的公开坐标并保存在本机浏览器。这不是 Find My API，无法自动刷新。

请勿输入 Apple ID、密码或验证码。未填写实际报告时间时，记录会标明采集时间，而不是声称刚刚发生的定位。

Google Maps 多点图层

不填 API key 可预览单个 Google 地图标点。要在 Google 地图底图上同时显示所有标点和轨迹，需要启用 Google Maps JavaScript API。

Key 仅用于当前浏览器会话，不提交到仓库。务必在 Google Cloud 将网站来源限制为 https://wangcanhao-cmd.github.io/*，并仅允许 Maps JavaScript API。

数据来源说明：可从「查找 → 路线」生成的 Apple 地图链接手动导入 AirTag 目的地坐标，或使用模拟点、手动输入、文件、iPhone GPS。地图链接不是 Find My 原始位置报告；iPhone GPS 不是 AirTag 独立定位。本站没有登录 Apple 账户，也不会自动抓取 AirTag。Google 地图可能向 Google 发送所显示的坐标；浏览器本地数据不是加密保险库。实际报告时间与采集时间分别存储。
