# Study Mississippi

Initial concept website for **Study Mississippi**, developed inside the public `OpenAI-Pub` repository.

## Purpose

A statewide international-education gateway inspired by the information architecture of Study Louisiana, while using a distinct Mississippi identity and visual system.

## Current sections

- Why Mississippi?
- Institutions
- International student resources
- Global Education Mississippi Association (GEMA)
- Events and community
- Contact

## Development notes

- Static HTML/CSS/JavaScript so the project stays portable.
- Can later be deployed to GitHub Pages, Netlify, Cloudflare Pages, Vercel, AWS, or adapted for another host.
- Hero image references a Library of Congress photograph of the Biloxi Lighthouse. The LOC record lists **no known restrictions on publication**.
- Institution directory, official contact information, partner logos, approved GEMA event photography, and final domain are still placeholders for the next revision.
