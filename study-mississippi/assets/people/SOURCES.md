# Portrait sources

These portraits were migrated from the legacy MAIE / StudyMississippi
Strikingly website. The original downloaded files are preserved in
`assets/people/original/`. The web copies in `assets/people/` are
generated directly from those originals with only EXIF orientation,
downscaling when necessary, and mild non-generative sharpening.

No AI face generation or facial-detail reconstruction is used.

Legacy source:
https://maiestudyms.mystrikingly.com/
